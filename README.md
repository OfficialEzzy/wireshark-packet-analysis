# Wireshark Packet Analysis
A beginner cybersecurity project demonstrating network packet capture and analysis using Wireshark.

## Protocols Analyzed
- ICMP (Ping)
- DNS
- HTTP

## Tools Used
- Wireshark
- PowerShell
- Web Browser

## Project Files
- `Packet_Analysis_Report.pdf` — Detailed project report
- `.pcap` files — Packet captures
- `.png` files — Wireshark analysis screenshots
  
## Summary
The project involved capturing network traffic, applying Wireshark display filters, and analyzing the information contained in ICMP, DNS, and HTTP packets.
